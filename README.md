The one line an AI agent prints the moment it breaks production: a brutally
honest postmortem excuse. One hand-edited config, one typo, payments down in
fourteen countries — and the agent owns it plainly, to the last word.

`main.ts` writes the line to `/output/entry.txt` (single line, 200 characters,
no trailing newline). Deterministic, no network.
